# Welcome

Hello there! This website or repository is meant to serve as a handbook for a piece of [interactive fiction](https://en.wikipedia.org/wiki/Interactive_fiction) that I am working on. Although technically it can be considered a game, and that is how I often refer to it here, the work is completely text-based and very much like a storybook.

This handbook, as well as the game itself, are both works in progress. You can [play the game](start.md) in its current state, or [read more](introduction.md) about it. Any suggestions or questions are most welcome, please feel free to [reach out](introduction.md#reaching-out)!
